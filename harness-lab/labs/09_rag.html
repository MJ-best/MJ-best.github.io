RAG는 원래 하네스 패턴이었다

  • RAG도 '배열에 무엇을 넣을지' 고르는 하네스 코드다.
  • 사전 주입(하네스가 검색) vs 검색 도구(모델이 검색) 두 방식.
  • 청크로 쪼개는 순간 관계가 흩어지고, top-k 는 연결 고리를 놓칠 수 있다.

1 개념

원문: 15장 RAG Was a Harness Pattern All Along

무엇이 깨지나

모델은 우리 회사 규정 문서를 모른다. 전부 프롬프트에 넣기엔 너무 많다(고 가정하자).

패치

문서를 청크로 쪼개 색인하고, 질문과 비슷한 top-k 만 배열에 넣는다. 넣는 방식은 둘:

  • 사전 주입 (augment) — 하네스가 먼저 검색해서 user 메시지 앞에 <retrieved> 로 붙인다.
  • 검색 도구 (search_docs) — 모델이 필요할 때 검색어를 골라 여러 번 검색한다 (agentic RAG).

여기선 의존성 없이 BM25 + 한글 글자 바이그램으로 구현합니다. 임베딩으로 바꿔도 하네스 쪽 구조는 같습니다.

비용 / 실패 지점

청크로 쪼개는 순간 문서 사이의 관계가 흩어진다. top-k 가 연결 고리를 놓치면 모델은 반쪽 근거로 답한다. python labs/09_rag/solution.py "대금지급 전에 검수가 끝나야 하나요?" → 삼자대사, 입고 문서가 빠진다. (→ Lab 10)

할 일

  • chunk_text — 문단 묶기
  • Index.score — BM25 공식
  • Index.search — 상위 k
  • augment — 사전 주입 형식

생각해볼 것

  • 데이터가 문서 8개뿐이라면, 검색을 하는 게 오히려 '누락'이라는 새 실패 지점을 만드는 건 아닐까요?
  • 청크 앞에 문서 제목을 붙이면(contextual chunk) 무엇이 좋아질까요?

예제 1 오픈북 시험: RAG 한 장 요약

비유 — RAG 는 오픈북 시험입니다. 책 전체를 외우게 하는 대신(학습), 시험 문제와 관련된 페이지 몇 장만 펴서 옆에 놓아 줍니다(검색 → 주입).

핵심은 "어떤 페이지를 펴 줄 것인가"이고, 그건 모델이 아니라 하네스 코드가 정합니다.

import solution as rag

index = rag.Index(rag.load_docs())
question = "어음으로 지급해도 되나요?"
print(f"책(청크) {len(index.chunks)}장 중에서 관련 페이지를 고릅니다.\n")
q_tokens = set(rag.tokenize(question))
for score, chunk in index.search(question, k=2):
    # 청크에서 질문과 가장 많이 겹치는 문장을 보여 준다
    best = max(chunk["text"].splitlines(), key=lambda line: len(set(rag.tokenize(line)) & q_tokens))
    print(f"📄 {chunk['id']}  (점수 {score:.2f})")
    print("   " + best[:60] + "\n")

예제 3 BM25 점수표: 드문 단어가 점수를 만든다

# --------------------------------------------------------------- 토큰화 (제공)
def tokenize(text):
    """영숫자 단어는 그대로, 한글 단어는 글자 바이그램으로 쪼갠다.
    '대금지급은' → ['대금', '금지', '지급', '급은']  (형태소 분석기 없이도 부분 일치 가능)"""
    tokens = []
    for w in re.findall(r"[가-힣]+|[a-zA-Z0-9]+", text.lower()):
        if re.match(r"[가-힣]", w) and len(w) >= 2:
            tokens += [w[i:i + 2] for i in range(len(w) - 1)]
        else:
            tokens.append(w)
    return tokens


# ------------------------------------------------------------------ 청크 나누기
def chunk_text(text, source, max_chars=200):
    """빈 줄로 문단을 나누고, 문단을 순서대로 이어 붙이다가 max_chars 를 넘으면 새 청크를 시작한다.
    (문단 하나가 max_chars 보다 길면 그 문단 혼자 한 청크)
    반환: [{"id": f"{source}#{i}", "source": source, "text": ...}, ...]  (i 는 0부터)
    문단 사이는 "\\n\\n" 으로 잇는다."""
    # >>> TODO: 문단 단위로 묶어 청크 리스트를 만드세요
    paras = [p.strip() for p in re.split(r"\n\s*\n", text) if p.strip()]
    chunks, cur = [], ""
    for p in paras:
        if cur and len(cur) + 2 + len(p) > max_chars:
            chunks.append(cur)
            cur = p
        else:
            cur = f"{cur}\n\n{p}" if cur else p
    if cur:
        chunks.append(cur)
    return [{"id": f"{source}#{i}", "source": source, "text": c} for i, c in enumerate(chunks)]

def load_docs(docs_dir=DOCS_DIR, max_chars=200):
    chunks = []
    for path in sorted(glob.glob(os.path.join(docs_dir, "*.md"))):
        with open(path, encoding="utf-8") as f:
            chunks += chunk_text(f.read(), os.path.basename(path), max_chars)
    return chunks


# ----------------------------------------------------------------------- 색인
class Index:
    K1, B = 1.5, 0.75

    def __init__(self, chunks):
        self.chunks = chunks
        self.tfs = [Counter(tokenize(c["text"])) for c in chunks]
        self.lens = [sum(tf.values()) for tf in self.tfs]
        self.avglen = sum(self.lens) / max(len(self.lens), 1)
        self.df = Counter(t for tf in self.tfs for t in tf)

    def idf(self, term):
        n, df = len(self.chunks), self.df.get(term, 0)
        return math.log(1 + (n - df + 0.5) / (df + 0.5))

    def score(self, query_tokens, i):
        """BM25 점수:  Σ_t idf(t) · tf·(K1+1) / (tf + K1·(1 − B + B·len/avglen))
        t 는 질문 토큰(중복 제거), tf 는 청크 i 에서 t 의 빈도. tf=0 이면 기여 0."""
        # >>> TODO: 위 공식을 구현하세요
        tf, length, s = self.tfs[i], self.lens[i], 0.0
        for t in set(query_tokens):
            f = tf.get(t, 0)
            if f:
                s += self.idf(t) * f * (self.K1 + 1) / (
                    f + self.K1 * (1 - self.B + self.B * length / self.avglen))
        return s
        # <<< TODO

    def search(self, query, k=3):
        """점수가 0 보다 큰 청크를 점수 내림차순으로 k 개. [(score, chunk), ...]"""
        # >>> TODO: 모든 청크를 채점하고 정렬해 상위 k 개를 반환하세요
        q = tokenize(query)
        scored = [(self.score(q, i), c) for i, c in enumerate(self.chunks)]
        scored = [x for x in scored if x[0] > 0]
        scored.sort(key=lambda x: -x[0])
        return scored[:k]

def format_hits(hits):
    """검색 결과를 모델이 출처를 인용할 수 있는 형태로."""
    if not hits:
        return "(검색 결과 없음)"
    return "\n\n".join(f'<doc id="{c["id"]}">\n{c["text"]}\n</doc>' for _, c in hits)

        sources = [c["source"] for _, c in self.index.search("대금지급 규정", k=3)]
        self.assertNotIn("07_사내공지_식당.md", sources)

    def test_augment_format(self):
        msg = lab.augment(self.index, "지급은 어떻게 하나요?", k=2)
        self.assertTrue(msg.startswith("<retrieved>"))
        self.assertIn('<doc id="06_대금지급_규정.md#0">', msg)
        self.assertTrue(msg.rstrip().endswith("질문: 지급은 어떻게 하나요?"))

    def test_agentic_rag_tool(self):
        brain = ScriptedBrain([
            reply(tool_use("search_docs", {"query": "어음 지급"}, id="S")),
            reply(text("어음 지급은 하지 않습니다 [06_대금지급_규정.md#0]")),
        ])
        msgs = [{"role": "user", "content": "어음으로 줘도 돼?"}]
        ex = lab.make_search_executor(self.index, lambda n, a: "base")
        run_loop(brain, msgs, [lab.SEARCH_TOOL], "sys", execute=ex)
        self.assertIn("어음 지급은 하지 않습니다", msgs[2]["content"][0]["content"])

    def test_multi_hop_gap(self):
        """관찰용: '대금지급 ↔ 검수'를 잇는 고리(삼자대사·입고) 문서가 top-3 에 없다.
        RAG 의 구조적 한계 — Lab 10 에서 온톨로지로 메웁니다."""
        sources = {c["source"] for _, c in
                   self.index.search("대금지급 전에 검수가 끝나야 하나요?", k=3)}
        self.assertFalse({"05_대사_통제.md", "02_입고_처리.md"} <= sources)
