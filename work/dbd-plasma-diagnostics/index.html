DBD Plasma Diagnostics (dbd-diagnostics)

대기압 유전체 장벽 방전(DBD) 플라즈마의 전압·전류 파형을 분석하고 유전체 표면 손상을 머신러닝으로 예측하는 석사 학위논문 코드의 재구성 패키지입니다.

왜 만들었나

논문 당시 노트북에 흩어져 있던 전기 진단과 분류 코드는 재현이 어렵고, 스케일링 누수와 지표 평균 방식 혼용 같은 문제가 있었습니다. 이를 검증 가능한 패키지로 정리해 다른 장치에서도 같은 방식으로 진단할 수 있게 했습니다.

주요 기능

  • V-I 파형 CSV(GW Instek 형식 포함)를 읽어 주기별 특징을 일괄 추출합니다
  • Manley 등가회로 기반 리사주(Q-V) 분석으로 C_d, C_g, 연소 전압, 주기당 에너지를 계산합니다
  • 논문 표 4의 14개 특징으로 6종 분류기를 학습하고 장치 단위 hold-out으로 평가합니다
  • 합성 파형 생성, 학습, 예측을 CLI와 Streamlit 앱으로 제공합니다

숫자로 보면

논문 표 4의 입력 특징 14개
비교 분류기 6종(LR, DT, RF, GB, SVM, kNN)
pytest 테스트 함수 27개, CLI 하위 명령 5개

어떻게 동작하나

  1. 파형 로드

    장비별 CSV를 파싱해 시간, 전압, 전류를 담은 Waveform 객체로 만듭니다.

    src/dbd_diagnostics/io.py

  2. 리사주 분석

    전압 극값으로 주기를 상승·하강 가지로 나누고 각각 두 직선으로 맞춰 C_total, C_dielectric, 연소 전압을 구합니다.

    src/dbd_diagnostics/lissajous.py

  3. 방전 펄스 통계

    방전 전류에서 노이즈 기반 강건 피크 검출로 반주기별 방전 펄스를 셉니다.

    src/dbd_diagnostics/discharge.py

  4. 플라즈마 물리량 계산

    환산 전계, 전자 이동도, 전자 밀도, 전자 온도를 계산합니다.

    src/dbd_diagnostics/plasma.py

  5. 특징 추출

    주기별 전기량과 플라즈마 물리량을 한 행의 특징 벡터로 합칩니다.

    src/dbd_diagnostics/features.py

  6. 분류 및 평가

    스케일러를 파이프라인 안에 넣고 장치 단위 leave-one-group-out으로 평가한 뒤 모델 번들을 저장합니다.

    src/dbd_diagnostics/ml.py

핵심 코드

src/dbd_diagnostics/lissajous.pyGitHub에서 보기 ↗
def sse_from(c, k):
    m, sx, sy, sxx, sxy, syy = (v[k] for v in c)
    vx = sxx - sx * sx / m
    if vx <= 0:
        return np.inf
    cxy = sxy - sx * sy / m
    vy = syy - sy * sy / m
    return vy - cxy * cxy / vx

cf = cums(x, y)
cb = cums(x[::-1], y[::-1])
best, best_k = np.inf, lo
for k in range(lo, hi):
    s = sse_from(cf, k - 1) + sse_from(cb, n - k - 1)
    if s < best:
        best, best_k = s, k
return best_k

누적합으로 모든 분할점의 두 직선 적합 오차를 O(n)에 계산해 방전 시작 지점을 찾습니다.

어려웠던 점

방전이 시작되는 꺾임점을 안정적으로 찾는 것이 핵심이며, 누적합으로 모든 분할 지점의 SSE를 O(n)에 계산해 두 직선 적합이 최소가 되는 지점을 고릅니다. 논문의 V_breakdown 식이 항등적으로 최대 인가전압과 같아진다는 점도 코드와 문서에 경고로 명시하고 별도 함수로 보존했습니다.
