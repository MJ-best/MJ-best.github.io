DBD Plasma Diagnostics (석사학위 논문 코드)

대기압 유전체장벽방전(DBD) 플라즈마의 전압·전류 파형으로 유전체 표면 손상을 진단하고 머신러닝으로 예측하는 석사 논문 재현용 Python 패키지입니다.

왜 만들었나

DBD 장치의 유전체 표면 손상은 눈으로 확인하기 전에는 알기 어렵고, 논문의 원본 노트북은 데이터 누수와 지표 혼용 문제가 있었습니다. 전기 신호만으로 손상 여부를 진단하고 재현 가능한 평가 방식을 제공합니다.

주요 기능

  • 오실로스코프 CSV(GW Instek 형식 포함)에서 주기 단위로 특징량 추출
  • Manley 등가회로 기반 리사주(Q-V) 분석으로 C_total, C_dielectric, C_gas, 연소전압, 주기당 에너지 계산
  • 14개 특징량으로 6종 분류기를 학습하고 장치 단위 hold-out으로 평가
  • dbd-diag CLI(extract, simulate, analyse, train, predict)와 Streamlit 앱 제공

숫자로 보면

분류 입력 특징량 14개, 비교 모델 6종(LR, DT, RF, GB, SVM, kNN)
pytest 테스트 함수 27개(6개 파일)
CLI 하위 명령 5개(extract, simulate, analyse, train, predict)

    오실로스코프 CSV를 읽어 Waveform 객체로 변환하고 GW Instek 형식을 자동 감지합니다.

  2. 주기 분할

  3. 리사주 분석

    Q-V 곡선의 상승·하강 분기를 각각 두 직선으로 맞춰 방전 전후 기울기와 개시 지점을 구합니다.

    src/dbd_diagnostics/lissajous.py

  4. 플라즈마 물리량

    환산 전계, 전자 밀도, 전자 온도를 Townsend·Paschen 관계와 표 보간으로 계산합니다.

    src/dbd_diagnostics/plasma.py

  5. 특징량 추출

    주기별로 논문 Table 4의 14개 특징량을 한 행으로 모읍니다.

    스케일러를 파이프라인 안에 넣고 장치 단위 leave-one-group-out으로 손상 여부를 평가합니다.

    src/dbd_diagnostics/ml.py

def baseline_normalize(df: pd.DataFrame, features: list[str], group: str, reference: pd.Series) -> pd.DataFrame:
    """Divide each feature by its per-group median over ``reference`` rows.

    ``reference`` must select captures known to be healthy *at deployment
    time* (e.g. the first hours of operation of each device), never rows chosen
    with knowledge of the label.
    """
    out = df.copy()
    for g, idx in df.groupby(group).groups.items():
        ref = df.loc[idx][reference.loc[idx]]
        if ref.empty:
            raise ValueError(f"group {g!r} has no reference rows")
        med = ref[features].median()
        out.loc[idx, features] = df.loc[idx, features] / med.replace(0, np.nan)
    return out

장치별 건강 구간 중앙값으로 특징량을 나누어 장치 간 오프셋을 제거하는 기준선 정규화입니다.

어려웠던 점

논문의 파괴전압 식은 대입하면 인가 전압 최댓값과 항등적으로 같아져 가스 방전 전압이 아닙니다. 이를 등가회로로 증명하고 연소전압을 별도 계산하며, 원 식은 재현용 함수로만 남겼습니다. 같은 장치의 캡처는 상관이 강해 무작위 분할이 낙관적이므로 장치 단위 평가를 사용합니다.
