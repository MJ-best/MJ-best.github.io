Who Scratch My Car 개인정보 처리방침

macOS·iPadOS 앱 Who Scratch My Car의 개인정보 처리방침을 GitHub Pages로 공개하는 단일 정적 페이지입니다.

왜 만들었나

앱 스토어 심사와 사용자 신뢰를 위해 공개 URL의 개인정보 처리방침이 필요합니다. 기기 내 처리되는 앱 데이터와 웹사이트가 수집하는 데이터를 구분해 명확히 알려야 합니다.

주요 기능

  • 앱은 계정 없이 동작하며 사진, 영상, 음성, 번호판 판독 결과를 기기에서만 처리한다고 명시
  • 앱과 별개인 배포 웹사이트의 Firebase 수집 항목(이메일, 기기 정보, 문의 내용)을 분리해 안내
  • 보관 기간과 열람·삭제 요청 경로를 고객 지원 문의 양식 링크로 제공
  • 한국어 본문과 영어 요약을 함께 제공
  • 다크 모드를 지원하는 외부 의존성 없는 단일 HTML

숫자로 보면

본문 조항 3개(앱, 웹사이트, 보관·삭제)
언어 2개(한국어 본문, 영어 요약)
파일 1개(index.html)로 구성된 외부 의존성 0개 페이지

어떻게 동작하나

  1. 앱 데이터 범위 명시

    계정과 분석 수집이 없고 사진·영상·음성·번호판 결과가 기기에서 처리됨을 1항에 서술합니다.

    index.html

  2. 웹사이트 수집 분리

    배포 웹사이트의 출시 알림과 문의 정보가 Google Firebase에 저장된다고 2항에 구분해 적습니다.

    index.html

  3. 보관·삭제 안내

    필요한 범위에서만 보관하며 삭제 요청은 공식 지원 문의 양식으로 받도록 3항에 안내합니다.

    index.html

  4. 영어 요약

    lang=en 섹션에 같은 내용을 요약해 해외 사용자와 심사자도 읽을 수 있게 합니다.

    index.html

  5. 정적 배포

    GitHub Pages가 index.html을 그대로 서빙하여 앱 스토어 제출용 공개 URL이 됩니다.

    index.html

핵심 코드

<h2>1. Mac 및 iPad 앱</h2><p>앱에는 계정이나 로그인이 필요하지 않으며, 개발자는 앱에서 개인정보나 이용 분석 데이터를 수집하지 않습니다. 사용자가 선택한 차량 파손 사진, 블랙박스 영상, 음성 및 번호판 판독 결과는 기기에서 처리되며 개발자나 외부 서버로 전송되지 않습니다. 임시 분석 파일은 기기에 저장되고, 사용자가 내보낸 리포트와 클립은 사용자가 선택한 위치에 저장됩니다. 내보낸 파일은 사용자가 직접 삭제할 수 있습니다.</p>
<h2>2. 공식 배포 웹사이트</h2><p>배포 웹사이트는 앱과 별개입니다. 출시 알림 신청이나 고객 문의를 제출하면 입력한 이메일 주소, 기기 및 블랙박스 정보, 문의 유형과 내용을 Google Firebase에 저장하여 알림을 보내거나 문의에 답하는 데 사용합니다. 사이트 이용 통계가 활성화된 경우 웹페이지 방문과 양식 이용 등의 이벤트를 집계합니다. 앱에서 분석한 사진이나 영상은 웹사이트에 전송되지 않습니다. 문의 양식에는 번호판, 영상 또는 민감한 정보를 제출하지 마세요.</p>
<h2>3. 보관 및 삭제 요청</h2><p>신청 및 문의 정보는 알림 발송, 문의 처리 또는 법적 의무에 필요한 범위에서 보관합니다. 열람이나 삭제를 요청하려면 <a href="https://who-scratch-my-car.vercel.app/#faq">공식 고객 지원 문의 양식</a>을 이용해 주세요.</p>

앱의 기기 내 처리 범위와 웹사이트 수집 범위를 별도 조항으로 나눈 핵심 본문입니다.

어려웠던 점

앱 자체는 데이터를 수집하지 않지만 배포 웹사이트는 Firebase로 정보를 수집하므로, 두 범위를 혼동 없이 나눠 서술하는 것이 핵심입니다. 문의 양식에 번호판이나 영상을 제출하지 말라는 경고도 함께 넣었습니다.
