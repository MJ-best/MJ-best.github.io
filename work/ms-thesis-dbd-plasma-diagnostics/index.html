DBD Plasma Diagnostics

대기압 유전체 장벽 방전(DBD) 플라즈마의 전압·전류 파형으로 전기적 진단 값을 계산하고, 유전체 표면 손상을 머신러닝으로 분류하는 석사 논문 재현용 파이썬 패키지입니다.

왜 만들었나

DBD 소자는 오래 쓰면 유전체 표면이 손상되지만, 파형만으로 상태를 판단할 기준이 없습니다. 논문의 노트북 코드는 데이터 누수와 지표 혼용 문제가 있어 이를 검증 가능한 형태로 다시 정리했습니다.

주요 기능

  • 오실로스코프 CSV(GW Instek 형식 포함)에서 RMS, 에너지, 전하, 방전 펄스 통계 추출
  • Manley 등가회로 기반 리사주 분석으로 C_total, C_dielectric, C_gas, 소화 전압 계산
  • Paschen 곡선, 환산 전기장, 전자 밀도·온도 추정
  • LR, DT, RF, GB, SVM, kNN 6종 분류기와 소자 단위 hold-out 평가
  • CLI와 Streamlit 앱으로 학습·예측 및 회로 시뮬레이터 제공

    CSV를 읽어 시간, 전압, 전류를 담은 Waveform 객체로 만듭니다.

  2. 전기량 계산

    전류의 오프셋을 제거하고 적분해 전하와 RMS, 주기당 에너지를 구합니다.

    src/dbd_diagnostics/electrical.py

  3. 리사주 분석

    전압 상승·하강 구간마다 두 직선 구간을 맞춰 방전 전후의 기울기(정전용량)와 점화 지점을 찾습니다.

  4. 방전·플라즈마 변수

    방전 펄스를 검출하고 전자 밀도와 전자 온도를 추정합니다.

  5. 특징 벡터 생성

    주기별로 논문 표 4의 14개 특징을 한 행으로 모읍니다.

핵심 코드

src/dbd_diagnostics/lissajous.pyGitHub에서 보기 ↗
def sse_from(c, k):
    m, sx, sy, sxx, sxy, syy = (v[k] for v in c)
    vx = sxx - sx * sx / m
    if vx <= 0:
        return np.inf
    cxy = sxy - sx * sy / m
    vy = syy - sy * sy / m
    return vy - cxy * cxy / vx

cf = cums(x, y)
cb = cums(x[::-1], y[::-1])
best, best_k = np.inf, lo
for k in range(lo, hi):
    s = sse_from(cf, k - 1) + sse_from(cb, n - k - 1)
    if s < best:
        best, best_k = s, k
return best_k

누적합으로 모든 분기점의 두 직선 잔차를 O(n)에 계산해 비방전·방전 구간의 경계를 찾습니다.

어려웠던 점

리사주 평행사변형에서 방전이 시작되는 지점은 점진적으로 나타나 직선 교점이 불안정합니다. 모든 분기점 후보에 대해 누적합으로 두 직선의 잔차를 O(n)에 계산해 최적 분기점을 고르고, 그 데이터 점을 점화 지점으로 사용합니다.
