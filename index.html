서버 없이 돌아가는 구조

따로 서버를 빌리지 않고 GitHub 하나로 화면, 배포, 예약 실행까지 해결합니다. 화면은 GitHub Pages에 올리고, 정해진 시간마다 돌아야 하는 일은 GitHub Actions가 대신 실행합니다. 결과는 다시 저장소에 커밋되어 페이지에 바로 나타납니다. 앞으로 만드는 앱도 이 구조 위에 붙여 나갑니다.

01저장소코드와 데이터, 실행 결과를 모두 Git에 둡니다. 변경 이력이 곧 백업입니다.
02Actions · 예약 실행cron으로 30분·매일·평일 18시처럼 정해진 때에 작업을 돌립니다. 비밀 키는 Secrets에 둡니다.
03결과 커밋수집·계산·요약한 결과를 봇이 저장소에 다시 커밋합니다.
04Pages · 배포push가 되면 정적 페이지가 자동으로 다시 배포됩니다.
05브라우저폰·PC 어디서든 링크 하나로 엽니다. 무거운 계산은 브라우저 안에서 합니다.

작업 방식

대부분 제가 직접 쓰려고 만들었습니다. 그래서 설치 없이 바로 열리고, 오프라인에서도 돌아가고, 계산 결과를 검증할 수 있게 만드는 데 공을 들입니다.

  • 설치 없음가능하면 정적 페이지 하나로. 브라우저에서 DAX·IOS·Python을 바로 실행합니다.
  • 직접 구현DAX 평가기, CLI 파서, 천문 계산처럼 핵심 로직은 라이브러리에 기대지 않고 직접 짭니다.
  • 테스트계산이 들어간 프로젝트는 단위 테스트와 실제 기기 시험 기록을 함께 남깁니다.
  • 다국어한국어·영어·러시아어·일본어 사용자를 함께 고려합니다.
