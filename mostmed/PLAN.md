# MostMed — 러시아 환자 ↔ 한국 병원 연결 에이전시 홈페이지 기획서

> 데모: https://mj-best.github.io/mostmed/  
> 상태: v0.1 정적 데모 (GitHub Pages) — 병원·가격은 모두 **예시 데이터**

## 1. 목표

러시아어권 환자가 **어떤 수술·시술이 있는지 한눈에 보고, 2번의 탭 안에 에이전트(나)에게 연락**하게 만든다.

- 핵심 지표: 방문 → 문의(텔레그램/왓츠앱/폼) 전환율
- 차별점: 대형 플랫폼은 "병원 카탈로그", 우리는 **"러시아인 의료통역 전문가가 직접 동행"** — 사람이 보이는 1:1 서비스

## 3. 사용자 동선

```
홈 → [검색 "колено"] 또는 [카테고리 선택]
   → 시술 목록 (가격대·체류일·회복)
   → [＋ В мой план] 여러 개 담기  /  [Узнать цену] 바로 문의
   → 하단 "Мой план" 시트: 이름·도시·연락채널 입력
   → Telegram / WhatsApp으로 시술 목록이 자동 작성된 메시지 전송
```

- 회원가입 없음. 첫 문의까지 입력 필드 3개(이름, 연락처, 채널).
- MRI·진단서 등 서류는 메신저로 받는 것을 기본 안내(파일 업로드는 v2 Supabase Storage).

## 5. 데이터 모델 (Supabase 이관 기준)

데모는 `data/*.json`을 읽고, 같은 스키마를 `supabase/schema.sql`로 정의해 두었다.

- `categories` (id, slug, name_ru, name_ko, sort)
- `procedures` (id, category_id, name_ru/ko, desc_ru/ko, price_from_usd, price_to_usd, stay_days, recovery_ru/ko, popular, keywords)
- `clinics` (id, name, city, district, categories[], tags[], is_foreign_patient_registered)
- `leads` (id, created_at, name, city, channel, contact, message, procedure_ids[], status)

## 7. 법·운영 체크 (실서비스 전 확인 필요)
